# PixelNorte

Sitio web de PixelNorte, un estudio de diseño web. Presenta quiénes somos, los servicios que ofrece con sus precios estimativos y un formulario de contacto.

## Tecnologías
- HTML5 semantico
- CSS3 (Flexbox, Grid, Mobile First, con una media query a 700px)
- Git y GitHub
- Apache

## Estructura
- `index.html` - página principal
- `servicios.html` - tabla de servicios en blanco
- `contacto.html` - formulario de contacto
- `img/` - imágenes del sitio (logo)
- `style.css` - hoja de estilos compartida por las tres páginas´
- `.gitignore` - archivos que Git ignora

## Diseño
- El sitio está pensado primero para celular: el menú y el formulario se muestran en una sola columna.
- A partir de 700px de ancho, el menú pasa a una fila y el formulario se acomoda en dos columnas.
